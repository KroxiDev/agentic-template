# Fuentes documentales

Registrar documentos que expliquen el dominio, requisitos, procesos o decisiones del proyecto. Preferir enlaces a los originales; añadir documentos Markdown aquí solo cuando esta sea su ubicación acordada.

## Incorporar una fuente

1. Identificar el documento original, su propósito y las condiciones de acceso.
2. Registrar su ubicación y versión o fecha relevante, sin duplicar su contenido.
3. Al usarlo, citar la sección pertinente y advertir si su vigencia no pudo comprobarse.

Las convenciones que el agente necesita al comenzar se enlazan desde el [contexto del proyecto](../../context/project.md). El procedimiento común de consulta está en [conocimiento](../README.md).
