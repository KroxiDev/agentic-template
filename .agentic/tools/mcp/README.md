# Integraciones MCP

Espacio opcional para documentar servidores o conexiones MCP (Model Context Protocol) que expongan herramientas y recursos al entorno de agentes.

Esta carpeta no contiene servidores, clientes ni configuración de conexión. El proyecto decide si utiliza MCP y cómo habilita cada integración.

| --- | --- | --- | --- |
| `[PENDIENTE]` | `[PENDIENTE]` | `[PENDIENTE]` | No configurada |

## Incorporar una integración

1. Copiar [template.md](template.md) y completar el propósito, el cliente, el destino y las capacidades necesarias.
2. Documentar dónde se administra la conexión, sin copiar credenciales. La instalación o conexión real es una tarea separada de completar la ficha.
3. Cuando esté habilitada y su uso esté autorizado, comprobar las capacidades disponibles y registrar fecha, alcance y resultado de esa comprobación.
4. Añadir la ficha a este catálogo y al [catálogo de herramientas](../README.md).
